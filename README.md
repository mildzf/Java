# Java Learning Journey

A collection of Java programs, exercises, and small projects developed throughout my journey of learning Java.

This repository serves as a record of my progress as I learn the language, experiment with different concepts, and improve my problem-solving and programming skills.

## About This Repository

The programs in this repository represent different stages of my learning journey. Some are simple exercises focused on a specific concept, while others combine multiple concepts into more complete applications.

The goal is not to showcase production-ready software, but to **document the process of learning by building**.

As my understanding of Java grows, so will the complexity of the programs in this repository.

## What I'm Learning

Through these projects and exercises, I am working with concepts including:

* Java fundamentals and syntax
* Variables and data types
* User input and `Scanner`
* Conditional statements
* `switch` statements
* Loops and iteration
* Methods
* Arrays and collections
* Object-oriented programming
* Exception handling
* File handling
* Problem solving and algorithmic thinking
* Writing cleaner and more maintainable code

## Repository Structure

Programs are generally organized around the concepts or projects they were created to practice.

As projects become larger and more self-contained, they may be moved into their own dedicated repositories.

### Larger Projects

Larger or more complete applications will have their **own GitHub repositories** with dedicated documentation, setup instructions, and project-specific information.

This repository will remain focused on smaller programs, exercises, experiments, and projects that form part of my ongoing Java development.

## Learning Philosophy

I believe one of the best ways to learn programming is by building things, making mistakes, understanding why they happen, and trying again.

The code in this repository reflects that process.

Some solutions may change over time as I learn better approaches or discover more effective ways to solve a problem. Older programs are therefore also a snapshot of where I was in my learning at the time they were written.

## What's Next?

I'm continuing to expand my knowledge of Java and gradually moving from basic programming exercises toward larger and more structured applications.

My focus is on:

* Building practical projects
* Strengthening my understanding of Java

* Developing better problem-solving skills
